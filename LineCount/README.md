### LineCount

LineCount는 특정 폴더가 포함하는 코드/데이터/이진파일 정보를 구하고 시각화합니다.
path(폴더 경로), code_ext(코드 확장자), data_ext(텍스트 파일 확장자)를 적절히 수정하여 사용하십시오.

LineCount retrieves and visualizes information about code, data, and binary files contained in a specific folder.
Modify path (folder path), code_ext (code extension), and data_ext (text file extension) appropriately before use.
