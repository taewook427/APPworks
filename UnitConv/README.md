### UnitConv

> Password Manager disguised as a Unit Converter

시작 화면에서 미국 단위계와 미터법을 환산합니다.
입력 숫자로 미리 설정된 워드를 사용하면 비밀번호 관리 화면이 나옵니다.
최초 비밀번호는 0000 이며, 000000000000 으로 저장 데이터를 삭제할 수 있습니다.
관리 화면에서는 여러 페이지로 구성된 노트를 보거나 수정할 수 있습니다.

Convert between US units and the metric system on the start screen.
If you use a pre-set word as the input number, the password management screen appears.
The initial password is 0000, and you can delete saved data using 000000000000.
On the management screen, you can view or edit notes consisting of multiple pages.

| Types | US Units | Metric |
| :-- | :-- | :-- |
| Length | in, ft, yd, mi | cm, m, km |
| Weight | oz, lb | g, kg |
| Temperature | 'F | 'C |
| Volume | gal | L |
